# 設計41 メモの取り込み：オーナーに聞いて決めた読み方（設計40 の続き）

状態：規則を確定（2026-11-10 オーナー回答）。実装・関門①はこれから。
前提：設計40（ops/design/40-memo-import-natural.md）・決定0144。

## 0. 経緯
設計40 を本番に出したあと、2人の実メモと3つ目のメモ（ルーマニアンデット等）を通して、
読み方が決められない書き方が残った。オーナーに8問＋2問を聞いて決めた。

## 1. 制約（コードの事実）
- `karte_tr_sets.weight_kg` は REAL・0〜500・NOT NULL。**文字は入らない**（migrations/0025）
- `reps` は 1〜100・NOT NULL。**回数の無いセットは保存できない**
- `set_no` は 1〜10
- オーナー判断：**表は変えない。いまの欄で表す**（重さの文字欄の新設は別設計・今回やらない）

## 2. 決めた読み方
| # | 書き方 | オーナーの答え | 入れ方 |
|---|---|---|---|
| R1 | `60×5+3` `9×10+5` | +N は補助・フォースドレップ | 現状どおり補助の回数 |
| R2 | `赤チューブ×10` `赤チューブ×10+5` | 種目の下ならその種目のセット | 重さなし×10（＋補助）・セットのメモ「赤チューブ」。直前に種目が無ければ1件ずつ |
| R3 | `背中ベンチ台に押しつけて胸椎ストレッチ` | 登録済みの種目名が行の途中にあれば種目 | **提案**「種目にする（胸椎ストレッチ）＋残りの文をその種目のメモ」。自動にはしない（文中で別の種目に触れただけの所感を誤って種目にしないため・一覧で見て決める） |
| R4 | `55×10(+3更新)` | 自己ベスト更新の印 | 55×10 を数値に。括弧の中はそのセットのメモ |
| R5 | `×5+5自重` | 種目のセット | 重さなし×5＋補助5。「自重」は読み捨てず、セットのメモ「自重」 |
| R6 | `60×`（回数なし） | 今の欄で表す | セットにしない。直前の種目のメモを提案（設計40 の「セットのメモ」提案をやめる） |
| R7 | `×15ずつ 3種類` | ×15 を3セット | 重さなし×15 を3つ。「3種類」は種目のメモ。M は 2〜10 のときだけ（set_no の天井） |
| R8 | `16+16×10` | 片手16kgずつ | 16kg×10・セットのメモ「片手16kgずつ」。**左右が同じ数のときだけ**。違う（16+12）なら1件ずつ |
| R9 | `次67.5×` `次回70×5` | 次回の目標＝今日のセットではない | 「次」「次回」に続く数字はセットにしない。種目のメモを提案 |

## 3. 変えないこと
- 健康の言葉・名前らしい行には提案を付けない（I71・I55）。R3 の提案も同じ
- 黙って数値にしない・黙って捨てない（I64）。R2〜R8 で数値にした行も、計画の一覧に原文と行き先が出る
- 種目のメモ・セットのメモは会員の画面に出ない（member-karte の SELECT に無い）

## 4. 検査（実装時に書く）
- 実メモ3本（架空化）の期待値を固定：A・B・C（ルーマニアンデット）
- R1〜R9 それぞれ1本以上。R8 の左右違い・R7 の M=1／M=11・R2 の種目なし・R9 の「次」が文中にあるだけの行（例「次のセットで」）
- 壊す検査：R3 を自動にする／R8 の左右一致を外す／R9 を外す、で落ちること
