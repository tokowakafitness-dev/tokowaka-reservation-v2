# 設計70 種目の記録の書き方と折り返しを揃える（前回・日別・3か月より前・写す画面・取り込み・推移）

> 2026-11-27・CTO。関門② 2周で通過。オーナー報告（実機・トレーニングのタブの「前回（11/27） 6種目・16セット」のカード）。
> 番号は 69 を別のブランチ（予約の正本 D1 化 S2）が使うため 70。個人情報は書かない。

## 0. 目的（1行）
種目の記録を、種目名は1行で独立・セットはその下に1つの書き方で並べ、1セットの途中で折り返さないようにする（片手で読みやすく）。

## 1. 起きたこと（スクショの事実）
- 種目名とセットが横並び（`display:flex;justify-content:space-between`）で、両方が途中で折り返す（「フロアプッシュアブダ／クション」「32kg × 12・／10」）
- 書き方が種目で不揃い：印の無い回は「32kg × 12・10」（同じ重さ）／「70kg×10・90kg×10…」（重さが混ざると毎回・空白なし）／印が1つでもあると全部1セットずつ（「自重×10→10kg×10・10kg×10」＝ドロップの → が混ざる）
- 同じ組み立ての複製：`setLineOf`（前回・日別・3か月より前は exRows、写す画面）・`setOneLine` の直書き（取り込みの日の中身）・`impLine`（読み取る・取り込みのボタン）・自己ベストと月ごとの1行の `wLabel × r` の直書き・直す画面の印（marksOf の → ）

## 2. 比べた手段
| | 内容 | 面積 | 評価 |
|---|---|---|---|
| A | CSS だけ（横並びのまま折り返しを禁止） | 最小 | 採らない（長い名前で横にはみ出す・書き方の不揃いは残る） |
| B | **1つの部品（setPieces → setLineOf／setLineEl・exBlock）に寄せる。名前の行とセットの行を分け、セットは折り返さない小片に** | 画面だけ | **採る** |
| C | 会員の画面（liff/index.html の _mk*）も同じ部品に | 会員に出る画面（MEMBER_KARTE は off） | 今回は採らない（顧客に出る画面＝関門③が要る。別の PR で） |

## 3. 書き方（1つに）
- 「重さ × 回数」（× の前後に空白）。自重は「自重 × 10」
- 同じ重さが続く印の無いセットは「100kg × 15・15」。重さが変わったら「・90kg × 10」
- 補助「+補助7」・できない回「（無理）」・ドロップ「（ドロップ 40kg × 8・20kg × 8）」。→ は使わない
- 印のあるセットは前後とまとめない（どのセットの印か分からなくなる）
- 数字の無い種目は「実施のみ」（今どおり）

## 4. 見え方
- `exBlock`：種目名（太字・全幅・長ければ名前の中で折り返す）／その下にセットの行（13px）
- セットの行は小片（`.k-setp`・`display:inline-block;max-width:100%`）を並べる。小片は「1セット」か「同じ重さの続きの1回分（15）」かドロップの1段。塊と塊の間で折り返し、塊の中は1行に入る限り割らない（1行より長い塊だけ中で折り返す＝横にはみ出さない）。区切りの「・」は前の小片の尻に付く＝折り返した行の頭が「・」で始まらない（関門②）
- 同じ重さの判定は数として読めるものだけ（空・null・数でない値はまとめない）
- セットのメモ（「2セット目：…」）・数字の無い種目のメモは今どおり種目の下に字下げ
- 推移のチップ（`.k-exchip`）は1行（nowrap）。17字以上の名前だけチップの中で折り返す（省略しない）

## 5. 使う所（全部同じ部品）
前回のカード・日別の記録・3か月より前の記録（exRows）／写す画面（exBlock）／取り込みの日の中身（exBlock）／読み取る・取り込みのボタンと下見（impLine＝setLineOf）／記録の画面の「前回 11/3：…」（setLineOf）／自己ベスト・月ごとの1行（wr）／直す画面の印（marksOf：「ドロップ 自重 × 10」）。

## 6. 変えないこと・判定できないとき

- 会員の画面（liff/index.html）は変えない（§2 C）
