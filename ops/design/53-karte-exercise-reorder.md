## 5. 実装方式

### 5-1 データ（純粋な関数を1つに）
```
moveIndex(arr, from, to)   配列の写しを返す（from を抜いて to に入れる）。from・to が範囲外・同じなら元のまま
記録の画面：reorderItems(D, from, to)
  D.items = moveIndex(D.items, from, to)
  D.openEi：開いていた種目を同じ種目のまま開く（添字を付け替える）
  rest.pos.ei：休憩の帯が付いていた種目に付いたまま（添字を付け替える・restShift と同じ考え方）
  save()（失敗したら元の順に戻して1行で知らせる＝今の save の扱いと同じ）
AI の確認画面：rv.exercises = moveIndex(rv.exercises, from, to) → draw（rvFoot が一時保存する）
```
- 種目は配列の要素ごと動く（セット・✓・メモ・出所の印 src・regPart はその要素の中）＝**中身は変わらない**。I57（✓）・出所の印・登録の欄はそのまま付いて動く。
- 上限（20種目・60セット）は数が変わらないので関係しない。

### 5-2 つまみのドラッグ（pointer events・ライブラリを使わない）
- つまみ：`<button type="button" class="k-grip" aria-label="〇〇の順番を変える（上下の矢印キーでも動かせます）">≡</button>`、44×44px 以上、**`touch-action:none` はつまみだけ**（ほかの場所のスクロール・タップは今と同じ）。`user-select:none`。
- `pointerdown`（つまみの上だけ）→ `setPointerCapture`（無い端末では document で受ける）→ 押した種目の行を少し浮かせて（影・`transform:translateY`）、行の高さ分の空きを置く。
- `pointermove`：指の位置と、ほかの種目の行の縦の真ん中（`getBoundingClientRect`）を比べて、入る位置（to）を決め、空きを動かす。**この間は draw しない**（入力欄を作り直さない）。
- 自動スクロール：指が #karteRoot の上端・下端から 56px 以内なら、`requestAnimationFrame` で少しずつ #karteRoot をスクロールし、位置を測り直す。
- `pointerup`：to が from と違えば §5-1 で入れ替えて draw。`pointercancel`・画面を離れた・別の顧客＝元の順のまま（何も変えない）。
- 動かし始めの判定：つまみの上で 6px 以上動いたらドラッグ。それより小さければ「軽く押した」とみなし、§6 の「上へ／下へ」を出す。
- 入力中の値：記録の画面の入力欄は打つたびに D へ保存している（oninput で save）＝ドラッグの前に `document.activeElement.blur()` しても値は失わない。落とした後の draw でフォーカスは外れる（受け入れる）。
- **ライブラリは使わない**：外から読む台本は今 LINE の SDK だけ（index.html 403行）で、並べ替えの部品（SortableJS 等）を CDN から足すと、読み込みの失敗・版の固定・供給元の安全を新しく抱える。上の作りは数十行で足りる。

### 5-3 設計50・51 への影響
- 色（出所）：rvTokens は種目の中だけを見る（§1-7）＝並べ替えで崩れない。
- 種目の id（'e0'…・足した種目は 'eNx'）は要素に付いたまま動く＝描画の照合は id のまま。
- 一時保存：配列の順で保存し、復元しても同じ順（§1-7）。rv の版は変えない。
- reviewBuild：rv.exercises の順で items を作る＝記録の下書きの末尾に、確認画面で並べた順で入る。

## 6. 支援技術・キーボードでの代わりの操作

- つまみはボタン。フォーカスがあるとき **↑／↓ キー**で1つずつ動かす（フォーカスは動いた先のつまみに戻す）。
- **つまみを軽く押す**（6px 未満で離す）と、その種目の行に「上へ」「下へ」（各 44px）が出る。押すと1つ動く。ほかの場所を押すか、もう一度つまみを押すと消える＝**画面の読み上げを使う人・ドラッグがうまく動かない端末でも並べ替えられる**（§9-1 の未確認への備えも兼ねる）。
- 動いたら `aria-live="polite"` の1行で「〇〇を3番目に動かしました」（名前と位置だけ）。
- 一番上で「上へ」、一番下で「下へ」は押せない（disabled）。
